In response to Dart Spark's [video](https://www.youtube.com/watch?v=WsWNWzSwVUA) showcasing well-hidden cuts in Dream's "Uncut" Manhunts, this project was created.

TickKeeper is a client-side Fabric mod that locally saves and restores the HUD tick counter when rejoining worlds or servers. The goal is to help maintain consistent hunger-bar jitter patterns, making cuts less noticeable and preserving the illusion of uninterrupted footage.

Works for Minecraft Java version 26.3
